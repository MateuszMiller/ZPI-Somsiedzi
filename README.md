# KwadrApp

Aplikacja do zarządania akademikami, łączaca w sobie funkcje socjalizacji oraz zarządanie współlokatorami

## Funkcjonalności:

  -Rejestracja przez numer pokoju.

  -Tablica ogłoszeń (np. pożyczysz suszarkę? ktoś sprzedaje książkę?).

  -Wydarzenia w akademiku z kalendarzem

  -Podział obowiązków między współlokatorami
